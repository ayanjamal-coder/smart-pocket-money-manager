# 💰 Smart Pocket Money Manager

A sleek, lightweight, and user-friendly personal finance tracker built with **Python** and **Streamlit**. Designed for individuals to effortlessly manage their daily expenses, categorize spending, and maintain persistent financial records using a local JSON-based datastore—requiring no complex database setup.

---

## 🌟 Features

* **Persistent Storage:** Automatically saves all transactions to a local `expenses.json` file so your data stays safe between sessions.
* **Interactive Dashboard:** Real-time metrics tracking **Total Spend** and **Total Entries**.
* **Categorized Expenses:** Group transactions into predefined categories (*Food, Travel, Study, Entertainment, Other*).
* **Dynamic UI:** Built with Streamlit for a fast, responsive, and modern web interface.
* **Data Management:** Quick-action options to view full transaction history and clear records instantly.

---

## 🛠️ Tech Stack

* **Python 3.8+**
* **Streamlit** (Frontend Web Framework)
* **JSON** (Lightweight Document Storage)
* **OS Module** (File Handling & Persistence)
