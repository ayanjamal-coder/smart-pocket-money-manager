# 💰 Smart Pocket Money Manager

A sleek, lightweight, and user-friendly personal finance tracker built with **Python** and **Streamlit**. Designed to effortlessly manage daily expenses, categorize spending, and maintain persistent financial records using a local JSON-based datastore—requiring no database configuration.

---

## 🌟 Key Features

* **Data Persistence:** Automatically saves all transactions to a local `expenses.json` file.
* **Real-time Overview:** Instant metrics for **Total Spent** (in PKR) and total transaction count.
* **Categorization:** Classify spending under *Food, Travel, Study, Entertainment, or Other*.
* **Interactive UI:** Dynamic table view powered by Streamlit.
* **Data Management:** Quick action button to clear and reset stored records.

---

## 🛠️ Tech Stack

* **Language:** Python 3.8+
* **UI Framework:** Streamlit
* **Data Storage:** JSON (`expenses.json`)
